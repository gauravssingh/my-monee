# Playwright Frontend Testing Skill for MyMonee

This skill provides multi-viewport automated testing, visual regression capture, and interactive debugging for the MyMonee web application (`http://127.0.0.1:8477/`).

---

## 1. Quick Capabilities & Commands

The skill includes a dedicated parameterized Python test runner at:
`./.agents/skills/playwright-frontend-testing/scripts/ui_test_runner.py`

### Common Workflows

#### A. Run full automated suite (Mobile + Desktop + Console Error checks)
```bash
source .venv/bin/activate
python .agents/skills/playwright-frontend-testing/scripts/ui_test_runner.py --all
```

#### B. Test a specific page or flow
```bash
# Test Overview month carousel & spending breakdown (mobile)
python .agents/skills/playwright-frontend-testing/scripts/ui_test_runner.py --page overview --mobile

# Test Settings tabbed navigation, categories accordion & OAuth layout
python .agents/skills/playwright-frontend-testing/scripts/ui_test_runner.py --page settings --mobile

# Test Transactions page filters, pagination & card layout
python .agents/skills/playwright-frontend-testing/scripts/ui_test_runner.py --page transactions --mobile

# Test Accounts & Statements page
python .agents/skills/playwright-frontend-testing/scripts/ui_test_runner.py --page accounts --desktop
```

#### C. Interactive Headful Debugging (Live Browser Window)
```bash
# Open live Chromium session in iPhone 14 mobile emulation
python .agents/skills/playwright-frontend-testing/scripts/ui_test_runner.py --page overview --interactive --mobile

# Open live Chromium session in Desktop resolution (1200x850)
python .agents/skills/playwright-frontend-testing/scripts/ui_test_runner.py --page settings --interactive --desktop
```

## 2. Authentication & Local Ledger Bypass

MyMonee protects financial routes with a local master PIN / session token. When running Playwright:

1. **Automatic Token Minting**: The test runner loads `auth_secret_key` directly from SQLite via `get_session_factory()` and mints a valid session token (`session:<timestamp>:<hmac>`).
2. **Init Script Injection**: The runner injects `localStorage.setItem('mymonee_auth_token', token)` before every page navigation so tests bypass the lock screen seamlessly without resetting user PINs.

## 4. UI Testing & Inspection Checklist

When verifying UI changes or debugging redesigns:

### Overview Page
- [ ] Month strip carousel centers active month with bold typography.
- [ ] Left (`‹`) and Right (`›`) chevrons smoothly navigate adjacent months.
- [ ] Contextual `[THIS MONTH]` button only displays when viewing a non-current month, and snaps back when tapped.
- [ ] Spending cards and category breakdown bars render properly without overflow.

### Settings Page
- [ ] Horizontal tab strip (`General`, `Gmail`, `Categories`, `AI`, `Data & Storage`, `System`) switches active panels cleanly.
- [ ] URL query parameter stays in sync (`/settings?tab=<tab_id>`).
- [ ] **Gmail Tab**: Connection status pill, action buttons (`Incremental Sync`, `Sync 2026 Dataset`, `Disconnect`), and mobile-stacked OAuth `.json` card.
- [ ] **Categories Tab**: Expandable accordion rows, semantic icons (🍔 Food, 🚗 Car, ✈️ Travel, etc.), search filter, and expense type segmented pills (`Essential`, `Discretionary`, `Financial`, `Investment`, `Transfer`).
- [ ] **Mobile Scroll Clearance**: Scrolled to bottom, verifying `min-height: 100dvh` and no content cutoff by browser footer bars.

### Transactions & Review Pages
- [ ] Desktop table switch vs mobile transaction cards.
- [ ] Sticky bottom action bar (`Review & Bulk Actions`) properly sits above safe area (`--sab`).
- [ ] Category dropdowns and inline editing modals open and close cleanly.
